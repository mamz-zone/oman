# CLAUDE.md

## Language
- Always reply to the user in **Arabic**.

## Video / image editing requests (Reels, covers)
- The approved theme and style for ALL future reels and cover images is documented in
  `reels-kit/STYLE_GUIDE.md`. Read it first and follow it exactly.
- `reels-kit/` contains the working templates (HTML/JS renderer, cover template), the Python
  pipeline scripts (transcription, face tracking, object tracking, sound design), fonts, and
  reference images (`reels-kit/reference/`, including the Instagram safe-zone reference —
  reference only, never composite it into the output).
- Never alter the user's face or voice beyond cropping/scaling and gain.
