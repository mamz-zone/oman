# Reels Kit — الثيم المعتمد للريلز والكفرات

هذا هو الستايل المعتمد رسميًا لكل الفيديوهات (ريلز) والصور (كفرات) القادمة.
المرجع الأول: ريلز **Lockdown 4** (انظر `reference/`).

---

## 1. قواعد ثابتة (لا تتغير)

1. **الرد دائمًا بالعربي.**
2. **لا تعبث بالوجه ولا بطريقة الكلام**: الوجه قصّ وتصغير فقط — بدون فلاتر، تنعيم، grain، تلوين، أو interpolation. الصوت: بدون compressor/EQ، فقط ضبط مستوى (gain) لأن التسجيل يجي عالي جدًا (~ -8 LUFS).
3. **60 فريم** فعلي، وأعلى جودة: ماستر 4K (2160×3840) + نسخة انستجرام 1080×1920.
4. **الوجه داخل دائرة** متوهجة وقت الكلام، وباقي الشاشة موشن جرافيك SaaS يتناسق مع الكلام.
5. **اللقطات التطبيقية/الأمثلة** (اللي فيها حواف سوداء) تنعرض في **كرت بالمنتصف مقتطع بدون حواف سوداء**، والانتقال إليها بتحوّل الدائرة إلى الكرت (morph) مع flash يخفي القطع.
6. **Instagram Safe Zone** (`reference/instagram-safe-zone.png`) — مرجع فقط، لا يظهر في المونتاج:
   - أعلى 250px فاضي من المحتوى المهم.
   - أسفل 320px (y > 1600) فاضي.
   - يمين 120px من y=1130 لتحت (أيقونات الانستجرام).
   - هوامش جانبية 120px → منطقة المحتوى: x 120–960, y 250–1600.
   - للكفر: كل المهم داخل القص الوسطي 3:4 (y 240–1680) لأنه اللي يظهر في شبكة البروفايل.
7. **ساوند ديزاين قوي** على كل حركة وانتقال (انظر القسم 5).
8. **الكابشن ديناميكي** كلمة-بكلمة على توقيت الصوت — ليس ثابتًا.

## 2. الهوية البصرية

| العنصر | القيمة |
|---|---|
| الخلفية | `#04060A` + توهجات radial (أخضر/تركوازي/أزرق) تتحرك ببطء |
| الأخضر الأساسي | `#2BFFA0` (glow) / `#00D68F` |
| تركوازي | `#22D3EE` |
| أزرق | `#3B82F6` / `#0A7CFF` |
| ذهبي (مجانًا/عروض) | `#FFF3B0 → #FFC24B → #FF8A00` |
| زجاج (Glass cards) | `linear-gradient(160deg, rgba(255,255,255,.10), rgba(255,255,255,.03))` + border `rgba(255,255,255,.14)` + radius 34px |
| خط عربي | **Alexandria** (800 للكابشن، 900 للعناوين الضخمة) |
| خط إنجليزي | **Sora** (700–800)، و Inter للرموز |
| العناوين الإنجليزية | كروم فضي متدرّج + رقم/كلمة مميزة بتدرّج أخضر متوهج |
| موتيف الخلفية | أرضية Mesh بمنظور ثلاثي الأبعاد تتموّج + نقاط + جزيئات صاعدة + grain خفيف (تحت الوجه فقط) + vignette |

### عناصر متكررة
- **دائرة الوجه**: حدّ أخضر 3px + glow، حلقة SVG بتدرّج تدور، ticks، ونص دائري يدور (`اسم المنتج • الميزة • البرنامج •`).
- **كبسولات (pills)**: `NEW` بتدرّج أخضر→تركوازي، وكبسولة عربية شفافة بحدّ أخضر.
- **كروت UI بستايل SaaS**: نافذة بنقاط macOS، sidebar، viewer، props، progress bar متوهج.
- **HUD**: زوايا brackets خضراء، scan line، شارة `● LIVE`.
- **تتبّع حقيقي**: إذا فيه لقطة لعنصر يتحرك، نتتبّعه فعليًا (optical flow + homography) ونرسم شبكة نقاط فوقه.
- **ختم ذهبي** للعروض المجانية، **كلمة ضخمة** (slam) للكلمات القوية مثل "أقوى".

## 3. الكابشن
- موقعه: مركز y≈1500 (1440–1580)، عرض x 110–970، RTL.
- مجموعات 2–4 كلمات حسب التوقيت.
- كل كلمة تدخل: scale .7→1 + blur 12→0 + translateY 34→0 (0.32s، back-ease).
- الكلمة الحالية: لون `#4DFFB0` + glow أخضر + نبضة scale 1.08.
- المصطلحات الإنجليزية (`After Effects`, `Mesh Tracking`…) داخل كبسولة متوهجة بخط Sora.
- كلمات القوة (مجانًا، أقوى…) أكبر حجمًا.
- نصحّح الإملاء الخليجي للمصطلحات (بلجن، تراكنج، اللوغو).

## 4. الحركة والكاميرا
- Easing: easeInOutCubic للحركات، back-ease للظهور، spring للسلام.
- Camera punch (scale +3–6%) + shake خفيف على الضربات.
- Flash + shockwave ring على اللحظات القوية.
- انتقال المشاهد: العناصر تخرج للأعلى مع blur، والجديدة تدخل من تحت مع scale .9 وblur.
- لا fade-to-black في النهاية (الريلز يعيد نفسه).

## 5. الساوند ديزاين (مولّد برمجيًا — `sfx.py`)
- **whoosh** على كل انتقال، **impact** (sub boom + crack + reverb) على الضربات، **braam** على الكلمات الضخمة.
- **riser** قبل اللحظات المهمة، **reverse swell** قبل القطع.
- **UI**: pops, clicks, blips (تتبّع)، chime عند الاكتمال، typing للكتابة، zap، shimmer للمجاني.
- **موسيقى خلفية**: pad سينمائي (Am–F–C–G) + نبض sub 90bpm + hi-ticks، مع ducking تحت الصوت.
- المكس: صوت -6.5dB، SFX -3dB، SFX ducking 30% وقت الكلام، limiter، loudnorm **-14 LUFS / TP -1.2**.

## 6. خط الإنتاج (Pipeline)
انسخ المجلد للـ scratchpad واشتغل منه (المسارات نسبية لمجلد الكت):
1. `transcribe.py` — Whisper large-v3 (faster-whisper) بتوقيت الكلمات. يحتاج huggingface.co + us.aws.cdn.hf.co، و `HF_HUB_DISABLE_XET=1`.
2. اكتشف حدود اللقطات المقتطعة (letterbox) بـ signalstats/cropdetect.
3. `facetrack.py` (MediaPipe blaze_face_short_range من storage.googleapis.com؛ يحتاج `libegl1 libgles2`) ← `prep_frames.py` (تنعيم) ← `extract.py` (قص الوجه 1400px→1120 وقص اللقطة التطبيقية).
4. `logotrack.py` — تتبّع عنصر في اللقطة التطبيقية (LK + homography) ← `render/meshtrack.js`.
5. عدّل `render/main.js` (التايملاين، CAPS، KF للبورتال) و `render/index.html` للمشاهد الجديدة.
6. معاينة: `node render/render.js prev 1 jpeg <frames>` ثم الفاينل: `node render/render.js out4k 2 jpeg 0-N 4` (Playwright، ~0.5s/frame).
7. `sfx.py voice48k.wav work` — عدّل cue sheet حسب التايملاين.
8. Encode:
   - 4K: `libx264 -preset slow -crf 12 -profile high -level 5.2 -pix_fmt yuv420p bt709 -r 60`, AAC 320k.
   - Instagram: `scale=1080:1920:flags=lanczos`, `-crf 15 -maxrate 30M -bufsize 60M -level 4.2`.
9. الكفر: `cover/cover.html` + `node cover/shot.js out.png 1|2` — فريم وجه نظيف (فم مغلق) مقصوص من الأصل 4K.
